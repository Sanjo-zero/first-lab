# Відповіді на питання для самоконтролю

1. **Чому важливо вказувати `user.name` та `user.email`?**
   Ці дані записуються в кожен коміт як інформація про автора. Завдяки їм видно, хто і коли вніс зміни, а GitHub за email прив’язує коміти до облікового запису.

2. **Яка різниця між `git pull` і `git fetch`?**
   `git fetch` лише завантажує нові коміти з віддаленого репозиторію, не змінюючи робочі файли та поточну гілку. `git pull` виконує `fetch` і одразу зливає (merge) отримані зміни в поточну гілку.

3. **Як скасувати останній коміт, не втрачаючи зміни у файлах?**
   `git reset --soft HEAD~1` – коміт скасовується, а зміни залишаються в індексі (`git reset HEAD~1` залишає їх у файлах без індексу).
